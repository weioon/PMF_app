# Project Specification: Personal Financial Management (PFM) System (EN / 中文)

## 1. Core Architecture & Tech Stack
- **Architecture Pattern**: Clean Architecture (Domain, Application, Infrastructure, API, and Mobile/Web Client).
- **Backend**: C# .NET 8/9 Web API, Entity Framework Core, SQLite (offline-first/local) or PostgreSQL/SQL Server.
- **Frontend / Mobile**: Angular (with Ionic/Capacitor for mobile build) + TypeScript + Tailwind CSS, using `@ngx-translate/core` (or `i18next`) for instant runtime switching between **English (`en`)** and **Simplified Mandarin (`zh-CN`)**.
- **Currency Default**: `MYR (RM)`, stored as `DECIMAL(18, 2)`.

## 2. Non-Negotiable Financial Domain Invariants
1. **Strict Double-Entry Ledger**:
   - `EXPENSE`: Decreases `SourceAccount.CurrentBalance`, increases category spending.
   - `INCOME`: Increases `DestinationAccount.CurrentBalance`, increases income source total.
   - `TRANSFER`: Atomically decreases `SourceAccount.CurrentBalance` and increases `DestinationAccount.CurrentBalance` inside a database transaction. Transfers (e.g., Bank A -> Bank B, or Bank A -> ASNB) MUST NEVER inflate monthly expense totals, except for any optional `TransferFee` which logs as a fee expense.
2. **Dynamic 4-Pillar Scalability (Unlimited User Freedom)**:
   - Users can freely create unlimited `AccountSubTypes` and `Accounts` under 4 immutable pillars:
     1. `ASSET_LIQUID` (Commercial Banks, Digital Banks, e-Wallets, Touch 'n Go NFC Card, Cash)
     2. `ASSET_INVESTMENT` (ASNB Fixed-Price, ASNB Variable, Fixed Deposit, Stocks/ETF, EPF)
     3. `LIABILITY` (SPayLater / BNPL, Credit Card, Car Loan, Personal Loan, Mortgage)
     4. `INCOME_SOURCE` (Salary, Freelance, Dividend Payout, Cashback)
   - Must provide real-time **Roll-Up Summary Views** for every Pillar and Sub-Type.
3. **Virtual Envelopes (Sinking Funds) Inside Bank Accounts**:
   - Physical bank accounts can hold multiple `VirtualEnvelopes` (e.g., Road Tax, Car Maintenance, Emergency Fund).
   - `UnrestrictedSpendableBalance = CurrentBalance - MinBalanceLimit - Sum(VirtualEnvelopes.AllocatedBalance) - Sum(UpcomingAutoDebits)`.
4. **Installment & Liability Engine (SPayLater, Credit Card EPP, Loans)**:
   - Creating a RM 150 SPayLater 3-month purchase immediately increases `SPayLater` total liability by RM 150, generates 3 monthly `InstallmentSchedules` (RM 50/month), and only counts RM 50 against the current month's cashflow budget.
   - Distinguishes Credit Card **Statement Float** (earmarked for full monthly payoff) from **Amortized Installments**.
   - Calculates **Debt Service Ratio (DSR %)** = `(Total Monthly Debt & BNPL Repayments / Net Monthly Income) * 100`.
5. **Investment Yield & ASNB Minimum Monthly Balance Engine**:
   - `ASNB_MIN_MONTHLY`: Tracks the lowest balance held between Day 1 and the last day of each calendar month. `MonthlyDividend = (LowestMonthlyBalance * (AnnualRate / 100)) / 12`.
   - `DAILY_COMPOUND`: Calculates daily interest `EndOfDayBalance * (AnnualRate / 100 / 365)`.
6. **Component-Level Guardrails & Proactive Suggestions**:
   - **Rule A (Operational Floor)**: Immediate alert if an account drops below `MinBalanceLimit` (e.g., Touch 'n Go NFC Card < RM 10.00 for toll/parking gates).
   - **Rule B (Auto-Debit Look-Ahead)**: Immediate + daily scheduled alert if an account balance is below `MinBalanceLimit + UpcomingAutoDebits + LinkedInstallments` due within `LookAheadAlertDays` (e.g., Bank A < RM 250 for monthly insurance deduction). Automatically queries other `ASSET_LIQUID` accounts with surplus funds (e.g., Bank B) to suggest an exact transfer amount.
   - **Rule C (Idle Cash Sweeper)**: Between the 25th and last day of the month, if a 0%-interest bank account holds excess cash above all buffers/auto-debits, suggest transferring the surplus to ASNB before the 1st of next month to capture full-month dividends.
7. **Pending Reimbursements (Split Bill Ledger) & Tax Relief Tagging**:
   - Expenses can split into `PersonalAmount` + `ReceivableAmount` (owed by friends) so group bills don't distort personal budgets.
   - Expenses can be tagged with annual Tax Relief buckets (e.g., Lifestyle, Sports, Medical) with receipt attachments.

## 3. Full Bilingual Support (English `en` & Mandarin `zh-CN`)
- Every UI screen, navigation tab, summary card, chart label, validation message, and financial warning/suggestion MUST support instant toggle between **English (`en`)** and **Simplified Mandarin (`zh-CN`)**.
- Default system seed data (Pillar names, Sub-Types, Categories, Tax Buckets) must store both `NameEn` and `NameZh` (or translation keys), while allowing users to input custom names in either language.
- Warning & Suggestion messages generated by the Rule Engine must use parameterized translation keys (e.g., `ALERT.LOW_AUTODEBIT_BALANCE`) so the user sees natural English or natural Mandarin dynamically.
